# SmartBudget - Week 3 Progress Report

## Project Details

Project Name: SmartBudget
Course: Web Engineering
Technologies: HTML, CSS and JavaScript
Data Storage: Browser LocalStorage
Current Branch: bug-fix

SmartBudget is a student-focused financial planning application. It helps users manage their budget, expenses and savings goals, and includes tools for spending analysis and what-if simulations.


## Project Structure

The main project folders and files are:

- index.html - Main dashboard page
- pages/ - Contains the Budget, Expenses, Savings, Simulator, Analysis and Settings pages
- css/ - Stylesheets for the application
- js/ - JavaScript files for application logic
- docs/ - Project documentation
- README.md - Project overview and setup instructions
